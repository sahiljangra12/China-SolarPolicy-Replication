# Data notice

The files in `00_Original_Package/` are an unchanged copy of the public replication package for:

> Zhang, H. et al. (2026). China's solar expansion policy reduces bird diversity. *Science* 393, 831.

Source: <https://github.com/jianke22/China-s-solar-expansion-policy-reduces-bird-diversity>

- `DATA/` holds the authors' 46 Stata data files, byte-for-byte as downloaded.
- `authors_CODE.do` is their code. Only the line that sets the data folder was edited.
- `authors_README.md` is their README. It asks users of the package to cite the paper.

The authors' package does not state a licence. The files are redistributed here only so that this replication can be run and checked, and all rights remain with the authors. If you are an author and would like the files removed, please open an issue and they will be replaced with a download script.

Datasets in the other folders (`*/data/*.dta`) were built from these files by the code in this repository.
